# We Do Wonder

A portfolio website showcasing the educational initiatives and community impact of We Do Wonder, a nonprofit organization based in Danang, Vietnam.

## About

We Do Wonder was founded in 2021 with a mission to inspire change in Vietnam through education and community engagement. The organization has directly impacted:
- 100+ young children
- 50+ youth  
- 100,000+ students through various initiatives and platforms

## Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Custom animations, grid layouts, and responsive design
- **JavaScript**: 
  - Lenis smooth scrolling library
  - Intersection Observer API for scroll-triggered animations
  - Custom scroll-based image expansion effects
